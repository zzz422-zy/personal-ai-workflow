# 四、重要定义


## 导数定义

若有限极限 $\lim_{h\to0}[f(x_0+h)-f(x_0)]/h$ 存在，则为 f′(x₀)。内点可导要求左右导数存在且相等；导数不是任意单侧斜率。



---

## 微分定义

若增量满足 $\Delta y=A\Delta x+o(\Delta x)$，则称函数在该点可微，微分 $dy=A\,dx$。一元函数在内点可微等价于可导，此时 A=f′(x₀)。dy 是线性主部，通常不等于实际增量 Δy。



---

# 五、核心公式


## 基本求导公式

以下公式均在函数有定义且可导的区间使用。

| 函数 | 导数 | 条件 |
|---|---|---|
| C | 0 | C 为常数 |
| x^α | αx^(α−1) | 一般实指数取 x>0；整数幂按其定义域 |
| e^x | e^x | x∈R |
| a^x | a^x ln a | a>0，a≠1 |
| ln\|x\| | 1/x | x≠0 |
| sin x | cos x | x∈R |
| cos x | −sin x | x∈R |
| tan x | 1/cos²x | cos x≠0 |
| arctan x | 1/(1+x²) | x∈R |
| arcsin x | 1/√(1−x²) | −1<x<1 |

和差、乘积与商：$(u\pm v)'=u'\pm v'$，$(uv)'=u'v+uv'$，$(u/v)'=(u'v-uv')/v^2$（v≠0）。

链式法则：$[F(g(x))]'=F'(g(x))g'(x)$，要求相应函数在对应点可导。参数方程 dy/dx=y′(t)/x′(t) 要求 x′(t)≠0。

## 2026-09-18 内容补全：求导与可导性例题

**自编例题 1：**求 y=ln(1+x²) 的导数。内层 1+x²>0，定义域为 R；链式法则给出 y′=2x/(1+x²)。在 x=0，dy=0，但 Δy=ln(1+Δx²) 通常非零，说明微分与增量不同。

**自编例题 2：**判断 f(x)=|x| 在 0 是否可导。右导数为 1，左导数为 −1，故不可导；不能把连续当成可导的充分条件。
